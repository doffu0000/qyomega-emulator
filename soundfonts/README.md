# Soundfonts for the emulator's Sound menu

Any `.sf2`, `.sf3`, `.dls` or `.sfogg` file placed in this folder shows up in the page's sound
menu next to the built in synthesizer (reload the page after adding one). Nothing here is the
the unit's own sound: the real unit's samples are in a wave ROM that is not part of the firmware.
