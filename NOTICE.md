## Not included, you supply it

* **The firmware image.** It is Yamaha's software and is not part of this program. Give the
  program your own copy of Yamaha's v1.37 update file (or the 2 MiB image made from it) on the
  page's setup screen, or put the image next to the program as `sequencer_flash.bin` (or point the
  `QYOMEGA_FIRMWARE` environment variable at it). The tests that boot the unit are skipped without it.
* **`boot.snap`.** A saved state of the unit after booting. It is made from the firmware, so it is
  not distributed either. `emu serve --fresh` builds it from your own image (about 35 seconds).
* **Soundfonts.** None is included (see the last section). Put any `.sf2`, `.sf3`, `.dls` or
  `.sfogg` file in `soundfonts/` and it appears in the Soundfont list.
  `GeneralUser-GS.voicemap.json` is a table of voice names and is part of this project.
* The unit's own sounds are Yamaha's and are not part of the firmware, so they are not here.
